# Changelog & Version History

All notable changes to the **Stronghold: Warlords Persian Localization Project** are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), adhering to [Semantic Versioning](https://semver.org/).

---

## [v1.2.0] - 2026-10-04

### Changed
- Standardized repository architecture to conform with the **ParsiSaz 2026 Localization Standard (L10N-STD-2026)**.
- Organized `fa.xml` and `lang.txt` into decoupled `loc/fa-IR/` and engine drop-in `game_assets/assets/interface/i18n/`.
- Updated signature `README.md` with installation guides and links to the [ParsiSaz Documentation Portal](https://parsisaz.github.io/parsisaz/).

---

## [v1.1.0] - 2023-04-18

### Added
- Completed warlord perk descriptions, campaign subtitles, and castle defense tooltips.

---

## [v1.0.0] - 2022-01-20

### Initial Release
- Initial Persian XML string translation for Stronghold: Warlords.
